# Working in this repo

- For heavy reading or mechanical work (whole books or chapters, many files, pulling quotes), use the `delegate-to-school-model` skill in `.agents/skills/`. It runs the free school model with the `school` command.
- Source texts go in `books/` as plain text with `=== PDF page N ===` markers. Cite those page numbers.
- Never print, commit or log the API keys in `/opt/school/env` or `~/.school/env`.
